# Quiz Party — เกมตอบคำถามสดแบบ Kahoot

ผู้จัดเปิดหน้า `/host` บนคอมพิวเตอร์/โปรเจกเตอร์ แขกสแกน QR แล้วเล่นบนมือถือ
ปรับธีมได้ (สี ฟอนต์ โลโก้ ภาพพื้นหลัง ชื่องาน) รองรับ 200+ คนพร้อมกัน
ชุดคำถามเริ่มต้นเป็นคำถามงานแต่ง 5 ข้อ แก้ไขได้ในหน้า `/host`

## รันบนเครื่องตัวเอง
```
npm install
npm start
```
เปิด http://localhost:3000/host (ผู้จัด) และ http://localhost:3000 (ผู้เล่น)

## นำขึ้นออนไลน์แบบไม่ต้องกรอกค่าเอง (Render Blueprint)
ในโฟลเดอร์มีไฟล์ `render.yaml` ตั้งค่าไว้ให้แล้ว (Build/Start Command, Health Check)
อัปโหลดขึ้น GitHub → Render → New → **Blueprint** → เลือก repo → Apply
ก่อนวันงานให้เข้า Dashboard แล้วเปลี่ยนแพลนจาก free เป็นแพลนเสียเงินระดับเล็กสุด

## นำขึ้นออนไลน์แบบกรอกเอง (ตัวอย่าง Render.com)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. Render → New → Web Service → เลือก repo
3. Build Command: `npm install` / Start Command: `npm start`
4. ได้ลิงก์ https://ชื่อ.onrender.com → เปิด `/host` เพื่อสร้างห้อง
แนะนำแพลนเสียเงินระดับเล็กสุดในวันงาน เพราะแพลนฟรีจะหลับเมื่อไม่มีคนใช้

## วิธีใช้ในงาน
1. เปิด `/host` → แก้คำถามและธีม → กด "สร้างห้องเกม"
2. ฉายจอ QR + PIN ให้แขกสแกน (เหลือแค่ใส่ชื่อ)
3. กด "เริ่มเกม": อ่านคำถาม → ตอบ → กราฟผล → ตารางคะแนน Top 5 → ... → โพเดียม 1-2-3
4. จบเกมดาวน์โหลดคะแนนทั้งหมดเป็น CSV ได้
5. ผู้จัดรีเฟรชหน้าจอได้ เกมไม่หาย / ผู้เล่นหลุดแล้วกลับมาก็เล่นต่อได้

## ทดสอบโหลดก่อนวันงาน (สำคัญ)
สร้างห้อง จดเลข PIN แล้วรัน:
```
node loadtest.js 123456 200 https://ชื่อ.onrender.com
```

## รูปภาพและวิดีโอ
- **ประกอบคำถาม**: ในช่องใต้คำถามวางลิงก์ YouTube, ลิงก์รูป หรือลิงก์ไฟล์ .mp4/.webm หรือกด "อัปโหลดรูป" วิดีโอจะเล่นอัตโนมัติแบบปิดเสียงบนจอผู้จัด (คลิกที่วิดีโอ YouTube เพื่อเปิดเสียงได้)
- **ในตัวเลือก**: กดปุ่ม 📷 ข้างตัวเลือกเพื่ออัปโหลดรูป ใส่เฉพาะรูปโดยไม่มีข้อความก็ได้ ผู้เล่นจะเห็นทั้งรูปและข้อความบนมือถือ
- รูปที่อัปโหลดจะถูกย่อให้อัตโนมัติและเก็บบนเซิร์ฟเวอร์ ให้มือถือทุกเครื่องโหลดจากแคชได้เร็ว ถ้าอยากใช้ภาพคุณภาพสูงให้ใช้ลิงก์รูปแทน
- วิดีโอในตัวเลือกยังไม่รองรับ (รองรับเฉพาะรูป)

## หมายเหตุ
- คะแนน: ตอบถูก 500–1000 ตามความเร็ว + โบนัสถูกติดกัน (สูงสุด +400)
- เสียง: เพลงประกอบ เสียงนับถอยหลัง เสียงถูก/ผิด แฟนแฟร์ตอนจบ สร้างด้วยโค้ดทั้งหมด มีปุ่ม 🔊/🔇 มุมขวาล่าง
  เบราว์เซอร์เล่นเสียงได้หลังแตะ/คลิกครั้งแรก (iPhone ต้องปิดโหมดเงียบ)
- ข้อมูลห้องเก็บในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ท เกมที่กำลังเล่นจะหาย
- ฟอนต์จาก Google Fonts และ QR จาก cdnjs ต้องมีอินเทอร์เน็ตที่หน้าจอผู้จัด
